# Beitragen

Danke für dein Interesse an Humanizer (Deutsch).

## Issues

Nutze das passende [Issue-Formular](https://github.com/marmbiz/humanizer-de/issues/new/choose).
Sicherheitslücken gehören nicht in öffentliche Issues; siehe [SECURITY.md](SECURITY.md).

## Pull Requests

1. Forke das Repository und arbeite in einem eigenen Branch.
2. Halte Änderungen klein und begründe das beobachtete Problem.
3. Führe `make verify` aus.
4. Aktualisiere Dokumentation und Tests, wenn sich öffentliches Verhalten ändert.

Neue oder materiell erweiterte deterministische Lint-Regeln müssen das vollständige
[Marker-Aufnahmeprotokoll](docs/marker-aufnahmeprotokoll.md) erfüllen. Dazu gehören
Positiv-, Negativ- und Grenzfälle, Fehlalarmgrenzen, Severity, erlaubte Aktion und das
Verbot, aus Treffern auf Autorschaft zu schließen.
