# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen werden für die aktuelle veröffentlichte Version bereitgestellt.
Die neueste Version steht unter [Releases](https://github.com/marmbiz/humanizer-de/releases).

## Sicherheitslücke melden

Bitte keine Sicherheitslücke in einem öffentlichen Issue veröffentlichen.
Nutze bevorzugt GitHubs Formular
[Report a vulnerability](https://github.com/marmbiz/humanizer-de/security/advisories/new).
Alternativ erreichst du den
Maintainer unter [info@martin-moeller.biz](mailto:info@martin-moeller.biz).

Beschreibe nach Möglichkeit die betroffene Version, das beobachtete Verhalten, die
Auswirkungen und die kleinsten Schritte zur Reproduktion. Der Empfang wird in der Regel
innerhalb von sieben Tagen bestätigt. Weitere Rückmeldungen folgen, sobald sich die
Einschätzung oder der Bearbeitungsstand ändert.

## Umfang

Sicherheitsrelevant sind insbesondere die mitgelieferten Python-Skripte, Dateioperationen,
Plugin-Manifeste und Installationswege für Claude Code und Codex. Allgemeine Qualitäts- oder
Erkennungsfehler ohne Sicherheitsauswirkung gehören in ein öffentliches Issue.
